# Бот «Подвал Евы»

Модерация группы: приём заявок с проверкой подписки на канал, приветствие с правилами, предупреждения (сгорают через 30 дней), муты, баны, автомодерация. Команды можно писать без «/», ответом на сообщение. Всё настраивается прямо в Telegram.

## Запуск с телефона (без компьютера)
1. **Токен.** В Telegram открой @BotFather → `/newbot` → скопируй токен.
2. **Файлы на GitHub.** Распакуй zip в приложении «Файлы». На github.com (в браузере) открой свой репозиторий → Add file → Upload files → выбери ВСЕ файлы из папки (папок внутри нет, так сделано специально) → Commit.
3. **Хостинг.** Нужен сервис, где программа работает постоянно (бот «слушает» Telegram). Подойдёт любой, где можно запустить воркер из GitHub-репозитория (например Railway или Fly.io) или обычный VPS. Бесплатные тарифы часто засыпают или меняются, поэтому для бота, который должен работать всегда, обычно нужен небольшой платный тариф. Актуальные цены смотри на сайте сервиса.
   - Создай проект из своего репозитория. Команда запуска: `python main.py` (в репозитории уже есть `Procfile` и `Dockerfile`).
   - В переменные (Variables) впиши: `BOT_TOKEN` и, если нужна проверка подписки, `CHANNEL_ID`.
   - **Важно:** подключи постоянный диск (Volume), например в `/data`, и добавь переменную `DB_PATH=/data/bot.db`. Без этого предупреждения будут стираться при каждом перезапуске.
4. **В Telegram.** Добавь бота в группу админом (удалять сообщения, банить/ограничивать, приглашать, закреплять), в канал тоже админом. Включи вступление по заявкам. Напиши в группе `/status`: бот покажет, чего ему не хватает.

ID канала (`-100…`) можно узнать через @getidsbot.

## Команды
Для всех:
- `/rules` или «Правила» — правила
- «кто админ» — список админов
- `/warns` — предупреждения (ответом на сообщение — чужие)
- `/help`

Для админов, ответом на сообщение нарушителя (можно без «/»):
- `Бан`, `Разбан`, `Кик`
- `Мут 1д` (также `30м`, `12ч`, `1н`), `Размут`
- `Пред`, `Снять пред`
- причину пиши на второй строке: `Бан` ⏎ `Следи за языком`
- то же со слэшем: `/ban`, `/mute 1д`, `/warn`, `/unwarn`, `/unmute`, `/unban`, `/kick`

Настройка из чата (админы):
- `/settings` — кнопки: включить/выключить мат, спам, рекламу, флуд, инлайн-ботов
- `/setrules` — ответом на сообщение с новым текстом: правила обновятся
- `/resetrules` — вернуть стандартные правила
- `/pinrules` — отправить и закрепить правила
- `/status` — проверка прав бота

## Автомодерация
Мат, спам стикерами/гифками, реклама (ссылки t.me), флуд, инлайн-боты. Админов не трогает. Пороги флуда и спама меняются в переменных (см. `.env.example`), свои каналы можно разрешить через `ALLOWED_LINKS`.

## Структура (все файлы в одной папке)
- `main.py` — запуск и подключение модулей
- `config.py` — настройки из переменных окружения
- `loader.py`, `db.py`, `utils.py` — бот, база, общие функции
- `rules.py` — стандартный текст правил
- `profanity.py` — фильтр мата
- `welcome.py` — заявки, подписка, приветствие
- `moderation.py` — команды модераторов
- `admin.py` — /settings, /setrules, /status
- `info.py` — /rules, «кто админ», /warns, /help
- `automod.py` — автомодерация (подключается ПОСЛЕДНИМ)

## Как добавить свою функцию
1. Создай файл, например `hello.py`:
   ```python
   from aiogram import F, Router
   from aiogram.types import Message
   router = Router()

   @router.message(F.text.lower() == "привет бот")
   async def hello(m: Message):
       await m.answer("Привет!")
   ```
2. В `main.py` добавь `import hello` и впиши `hello.router` в `dp.include_routers(...)` перед `automod.router`.

Токен не клади в репозиторий (`.env` уже в `.gitignore`). Если токен утёк — `/revoke` в @BotFather.
